# Untitled roguelike autobattler

A personal game development project built in Godot.

## Overview

This project explores complex strategy RPG systems, including:
- Procedural encounters
- Character progression
- AI behaviors
- Data-driven game architecture
The project is currently focused on gameplay systems and programming rather than final visual assets. Most art is temporary placeholder content.

## Game Systems

The player will spend most of his time evaluating and choosing abilities, fighters, and equipment. The game is focused on creating as many interesting decisions as possible, 
maximizing the resulting decision space of the interactions between many of the game systems.

- Godot
